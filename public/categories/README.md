# Category images

Put one image per category in this folder, named exactly after the category's web address name:

| Category | File name |
|---|---|
| Eyewitness Afterlife | `eyewitness-afterlife.jpg` |
| Numbers | `numbers.jpg` |
| Everyday Things | `everyday-things.jpg` |
| Nature | `nature.jpg` |
| The 7 Series (optional) | `the-7-series.jpg` |
| The 11, 12 Series (optional) | `11-12-series.jpg` |

`.jpg`, `.jpeg`, `.png` and `.webp` all work. Use lowercase names with hyphens, exactly as shown.

Sizes: Eyewitness Afterlife about 1600 × 1200 or larger; the others about 1200 × 600. Keep each under about 1 MB.

An image here is used instead of one chosen in WordPress. Series without their own image use the Numbers image.
