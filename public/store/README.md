# Store photos

Name photos after the product id in `src/data/store.ts`, numbered from 1:

- `seven-spirits-print-1.jpg`, `seven-spirits-print-2.jpg`
- `seven-flames-tee-1.jpg`
- `seven-flames-mug-1.jpg`
- `trail-of-sevens-guide-1.jpg`

The first photo is used on product cards. Square images around 1200 × 1200 work best. Without photos, products show artwork in the site's style.
